Privacy Policy — Tropika Publisher

Last updated: November 25, 2026

1. Who uses this application

Tropika Publisher is an internal tool used exclusively by the owner of the YouTube channel Tropika VI, on the owner's own computer. It has no public users.

2. Use of YouTube API Services

This application uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

3. Data accessed

With the owner's authorization (OAuth), the application accesses only the owner's own YouTube channel to: upload videos, set titles, descriptions, tags and thumbnails, schedule publication dates, and read the status of those uploaded videos.

4. Storage

The OAuth access token is stored only on the owner's computer. Video metadata comes from local project files. No data is stored on any server operated by this application.

5. Sharing

No data is sold, shared, disclosed, or transferred to any third party. Data is used only to publish the owner's own videos. The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Revoking access

Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions. Deleting the local token file also removes the application's access.
